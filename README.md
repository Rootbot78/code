## 简介

GitHub TUI 是一个基于 tkinter 的 GitHub 图形化管理界面，支持仓库管理、文件操作、Git 操作、PR 管理、Issue 管理等功能。

**前提条件：**
- 已安装 `gh` CLI 工具
- 已完成 GitHub 认证 (`gh auth login`)

---

## 快速开始

```bash
# 1. 克隆仓库到本地
git clone https://github.com/你的用户名/gh_tui.git

# 2. 进入目录
cd gh_tui

# 3. 运行程序
python3 gh_tui.py
```

**首次使用需认证 GitHub：**
```bash
gh auth login
```

## 功能详解

### 5.1 仪表盘

显示 GitHub 账号的整体状态概览。

**显示内容：**
- **认证状态** - 是否已登录 GitHub
- **用户名** - 当前登录的用户名
- **远程仓库总数** - GitHub 账户下的仓库数量
- **本地仓库总数** - 本地 `~/github/` 目录下的 Git 仓库数量

**快捷键说明列表** - 展示所有可用快捷键

---

### 5.2 远程仓库

管理 GitHub 上的远程仓库。

**工具栏按钮：**
| 按钮 | 功能 |
|------|------|
| 搜索 | 搜索 GitHub 仓库 |
| 刷新 (r) | 刷新仓库列表 |
| 新建 (n) | 创建新仓库 |

**搜索框** - 实时过滤当前显示的仓库

**仓库列表操作按钮：**
| 按钮 | 功能 |
|------|------|
| Info | 查看仓库详情 |
| Clone | 克隆到本地 |
| Upload | 上传文件到仓库 |
| Files | 查看仓库文件列表 |
| Fork | Fork 仓库 |
| Delete | 删除仓库 |

---

### 5.3 本地仓库

管理本地克隆的 Git 仓库（存储在 `~/github/` 目录）。

**工具栏按钮：**
| 按钮 | 功能 |
|------|------|
| 刷新 (r) | 刷新本地仓库列表 |

**仓库列表显示：**
- 仓库名
- 当前分支
- 更改状态（有多少文件被修改）

**仓库列表操作按钮：**
| 按钮 | 功能 |
|------|------|
| Commit | 提交更改 |
| Pull | 拉取远程更新 |
| Push | 推送到远程 |
| Branch | 分支管理 |
| Log | 查看 Git 提交历史 |

---

### 5.4 分支管理

管理本地 Git 仓库的分支。

**工具栏：**
- 仓库下拉选择 - 选择要管理的本地仓库
- 刷新 (r) - 刷新分支列表
- 新建 (n) - 创建新分支

**分支列表显示：**
- 分支名
- 上游分支（关联的远程分支）
- SHA（最新提交的短哈希）

**操作按钮：**
| 按钮 | 功能 |
|------|------|
| 切换 | 切换到该分支 |
| 删除 | 删除该分支（仅非当前分支） |

---

### 5.5 工作流

查看和触发 GitHub Actions 工作流。

**前提条件：** 本地仓库必须有 `.github/workflows/` 目录和 YAML 配置文件。

**工具栏按钮：**
| 按钮 | 功能 |
|------|------|
| 刷新 (r) | 刷新工作流列表 |
| 运行 (n) | 手动触发工作流 |

**工作流列表显示：**
- 工作流名称
- 最近运行状态（success/failure/无）
- 运行时间

**操作按钮：**
| 按钮 | 功能 |
|------|------|
| 运行 | 触发该工作流 |

---

### 5.6 议题

管理 GitHub Issues。

**工具栏：**
- 状态筛选 - 选择 `open`（开放）/ `closed`（已关闭）/ `all`（全部）
- 刷新 (r) - 刷新议题列表
- 新建 (n) - 创建新议题

**议题列表显示：**
- 编号
- 标题
- 状态
- 标签
- 创建时间

**操作按钮：**
| 按钮 | 功能 |
|------|------|
| 关闭/打开 | 关闭或重新打开议题 |
| 详情 | 查看议题详细内容 |

## 对话框详解

### 搜索仓库对话框

**用途：** 在 GitHub 上搜索仓库

**填写方式：**
1. 在搜索框输入关键词（如仓库名、主题等）
2. 点击「搜索」按钮或按 Enter 键
3. 双击列表中的结果可查看仓库详情

---

### 创建仓库对话框

**用途：** 在 GitHub 上创建新仓库

**填写字段：**
| 字段 | 说明 | 必填 |
|------|------|------|
| 仓库名称 | 新仓库的名字 | 是 |
| 描述 | 仓库的描述信息 | 否 |
| 私有仓库 | 勾选则创建私有仓库 | - |
| 初始化 README | 勾选则自动创建 README.md | - |
| 添加 .gitignore | 勾选则添加 Python 模板 | - |

---

### 仓库详情对话框

**用途：** 查看仓库的详细信息

**显示内容：**
- 仓库全名（owner/repo）
- 描述、默认分支、语言
- 星标数、Fork 数、开放议题数
- 创建时间、最后更新时间、URL

**操作按钮：**
| 按钮 | 功能 |
|------|------|
| Fork | Fork 该仓库到自己的账户 |
| Star | 给仓库加星标 |
| 提交记录 | 查看该仓库的 commit 历史 |
| PR 列表 | 查看该仓库的 Pull Requests |
| 关闭 | 关闭对话框 |

---

### 克隆仓库对话框

**用途：** 将远程仓库克隆到本地

**填写字段：**
| 字段 | 说明 | 默认值 |
|------|------|--------|
| 目标路径 | 本地存储路径 | `~/github/` |

**操作：** 点击「克隆」开始克隆过程

---

### 上传文件对话框

**用途：** 从本地上传文件到 GitHub 仓库

**填写字段：**
| 字段 | 说明 | 必填 |
|------|------|------|
| 选择本地文件 | 点击「浏览」选择要上传的文件 | 是 |
| 仓库内路径 | 文件在仓库中的保存路径（如 `src/main.py`） | 是 |
| 提交信息 | 这次上传的 commit 信息 | 是 |

---

### 删除仓库对话框

**用途：** 删除 GitHub 上的仓库（危险操作）

**确认方式：**
1. 输入仓库名称进行确认（防止误删）
2. 只有输入正确的仓库名才能点击「删除」

---

### 创建 PR 对话框

**用途：** 创建 Pull Request

**填写字段：**
| 字段 | 说明 | 必填 |
|------|------|------|
| 标题 | PR 的标题 | 是 |
| 描述 | PR 的详细描述 | 否 |
| 源分支 | 你要合并的分支名 | 是 |
| 目标分支 | 合并到的目标分支 | 否（默认 main） |

---

### 提交更改对话框

**用途：** 提交本地 Git 仓库的更改

**填写步骤：**
1. **选择文件** - 勾选要提交的文件（显示的是有更改的文件）
2. **输入提交信息** - 描述这次提交做了什么
3. **立即推送**（可选）- 勾选则提交后自动推送到远程

---

### 分支管理对话框

**用途：** 查看和切换分支

**显示内容：**
- 当前分支（绿色标记）
- 所有分支列表

**操作：**
- 点击「切换」切换到对应分支
- 点击「删除」删除对应分支

---

### 创建分支对话框

**用途：** 在本地仓库创建新分支

**填写字段：**
| 字段 | 说明 | 默认值 |
|------|------|--------|
| 分支名称 | 新分支的名字 | - |
| 基础分支 | 从哪个分支创建 | main |

---

### 运行工作流对话框

**用途：** 手动触发 GitHub Actions 工作流

**填写步骤：**
1. 从下拉菜单选择仓库（如果有多个本地仓库）
2. 点击「运行」触发该仓库的第一个工作流

---

### 创建议题对话框

**用途：** 在 GitHub 上创建 Issue

**填写字段：**
| 字段 | 说明 | 必填 |
|------|------|------|
| 标题 | 议题的标题 | 是 |
| 描述 | 议题的详细内容（支持 Markdown） | 否 |
| 标签 | 用逗号分隔的标签名 | 否 |

---

### 查看提交记录对话框

**用途：** 查看仓库的 commit 历史

**显示内容：**
- SHA（7位哈希值）
- 提交信息
- 作者
- 日期

---

### 查看 Git 日志对话框

**用途：** 查看本地仓库的 Git 提交历史

**显示内容：**
- SHA（7位哈希值）
- 提交信息
- 作者
- 日期

## 故障排除

### 认证失败
```bash
# 检查认证状态
gh auth status

# 如需重新登录
gh auth logout
gh auth login
```

### 网络错误
```
gh command error: Get "https://api.github.com/user": unexpected EOF
```
这通常是网络连接问题，请检查：
- 网络是否正常
- 是否使用了代理
- GitHub 是否可访问

### 提交失败
确保已配置 Git 用户信息：
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

### 本地仓库操作失败
- 确保本地仓库路径 `~/github/` 存在且有正确权限
- 确保 `.git` 目录完整

## 配置文件

**本地仓库存储目录：** `~/github/`

如需修改，编辑 `gh_tui.py` 第 20 行：
```python
LOCAL_REPO_DIR = os.path.expanduser("~/github/")
```
