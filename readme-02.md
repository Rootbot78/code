## 快速开始

### 环境要求

- Python 3.10 或更高版本
- GitHub CLI (`gh`) 已安装并登录
- 终端支持 ANSI 颜色

### 首次设置

```bash
# 1. 检查 gh CLI 版本
gh --version

# 2. 认证 GitHub 账号
gh auth login

# 3. 配置 git 凭据
gh auth setup-git

# 4. 运行应用
python3 /home/smg/github/gh_tui.py
```

### 运行应用

```bash
python3 /home/smg/github/gh_tui.py
```

## 功能详解

### 仪表盘

显示当前账号的概览信息：
- GitHub 用户名
- 认证状态
- 仓库总数
- 本地仓库数量
- 快捷键说明

**进入方式：** 按 `D` 或点击侧边栏「仪表盘」

---

### 远程仓库

管理 GitHub 上的仓库。

#### 查看仓库列表

1. 按 `R` 进入「仓库」视图
2. 自动加载你的远程仓库列表
3. 支持搜索过滤

#### 搜索仓库

1. 点击工具栏「搜索」按钮
2. 输入搜索关键词
3. 双击结果查看详情

#### 查看仓库详情

1. 点击仓库行的「Info」按钮
2. 可查看：
   - 描述、语言、星标数、Fork 数
   - 创建时间、最后更新时间
   - URL 地址

#### 克隆仓库

1. 选择目标仓库，点击「Clone」
2. 选择本地存储路径（默认 `~/github/`）
3. 点击「克隆」等待完成

#### 上传文件到仓库

1. 点击仓库行的「Upload」
2. 选择本地文件
3. 输入仓库内目标路径（如 `folder/file.txt`）
4. 填写提交信息，点击「上传」

#### 查看/删除仓库文件

1. 点击仓库行的「Files」
2. 查看仓库文件列表
3. 点击文件行的「删除」按钮可删除该文件

#### Fork 仓库

1. 点击仓库行的「Fork」
2. 自动在你的账号下创建 Fork

#### 删除仓库

1. 点击仓库行的「Delete」
2. 输入仓库名称确认
3. 删除操作不可撤销

#### 查看提交记录

1. 在仓库详情页点击「提交记录」
2. 查看最近 20 条提交

#### 管理 Pull Requests

1. 在仓库详情页点击「PR 列表」
2. 筛选 PR 状态（open/closed/all）
3. 点击「新建 PR」创建新的 Pull Request

### 本地仓库

管理本地已克隆的仓库（`~/github/` 目录）。

#### 查看本地仓库

1. 按 `L` 进入「本地仓库」视图
2. 显示所有本地 Git 仓库

#### 提交更改

1. 点击仓库的「Commit」按钮
2. 勾选要提交的文件
3. 输入提交信息
4. 可选择「立即推送到远程」

#### 拉取更新

1. 点击仓库的「Pull」按钮
2. 从远程拉取最新更改并合并

#### 推送更新

1. 点击仓库的「Push」按钮
2. 将本地提交推送到远程仓库

#### 分支管理

1. 点击仓库的「Branch」按钮
2. 查看所有分支
3. 切换或删除分支

#### 查看提交历史

1. 点击仓库的「Log」按钮
2. 查看本地 Git 提交历史

---

### 分支管理

专门管理本地仓库的分支。

#### 查看分支

1. 按 `B` 进入「分支」视图
2. 选择要查看的仓库
3. 显示所有分支（当前分支标有 `*`）

#### 创建分支

1. 点击工具栏「新建 (n)」
2. 输入新分支名称
3. 选择基础分支
4. 确认创建

#### 切换分支

1. 选择目标分支
2. 点击「切换」按钮

#### 删除分支

1. 选择要删除的分支
2. 点击「删除」按钮
3. 不能删除当前分支

---

### 工作流

查看和触发 GitHub Actions 工作流。

#### 查看工作流列表

1. 按 `W` 进入「工作流」视图
2. 显示所有本地仓库的 workflow 文件

#### 查看运行记录

1. 选择一个工作流查看最近运行状态

#### 触发工作流

1. 点击工作流的「运行」按钮

---

### 议题

管理 GitHub Issues。

#### 查看议题列表

1. 按 `I` 进入「议题」视图
2. 使用下拉框筛选：开放（open）、已关闭（closed）、全部（all）

#### 创建议题

1. 点击工具栏「新建 (n)」
2. 填写标题（必填）
3. 填写描述（支持 Markdown）
4. 添加标签（用逗号分隔）
5. 确认创建

#### 查看议题详情

1. 点击议题的「详情」按钮
2. 查看标题、描述、标签、创建时间

#### 关闭/重新打开议题

1. 选择议题
2. 点击「关闭」或「打开」按钮

## 快捷键

### 全局导航

| 按键 | 功能 |
|------|------|
| `q` | 退出应用 |
| `Ctrl+C` | 强制退出（备用） |
| `Esc` | 返回 |
| `r` | 刷新当前视图 |
| `D` | 跳转到仪表盘 |
| `R` | 跳转到远程仓库 |
| `L` | 跳转到本地仓库 |
| `B` | 跳转到分支管理 |
| `W` | 跳转到工作流 |
| `I` | 跳转到议题 |

### 列表导航

| 按键 | 功能 |
|------|------|
| `↑` / `k` | 向上选择 |
| `↓` / `j` | 向下选择 |
| `Enter` | 确认/进入 |

## 常见问题

### gh 命令未找到

```bash
# Debian/Ubuntu
sudo apt install gh

# 验证安装
gh --version
```

### 认证失败

```bash
# 登出并重新登录
gh auth logout
gh auth login
```

### 克隆失败

- 检查网络连接
- 确认仓库存在且有访问权限
- 确保目标目录为空或不存在

### 推送失败

- 检查是否已配置远程仓库
- 确认有推送权限
- 可能需要先拉取远程更新
